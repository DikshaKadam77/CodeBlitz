# Quiz Dashboard 🎯

A responsive and interactive quiz dashboard built using React.js and Vite.

## 🌐 Live Demo

[View Live Demo](https://quiz-dashboard-xi.vercel.app/)

## ✨ Features

- Interactive quiz interface
- Dynamic question and option display
- Score tracking
- Quiz completion screen
- Restart quiz functionality
- Responsive user interface
- Clean and modern design

## 🛠️ Tech Stack

- React.js
- JavaScript
- HTML5
- CSS3
- Vite
